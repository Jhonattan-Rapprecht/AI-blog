# Changelog — 2026-10-26

## Articles analytics and inline overview actions

- Grouped **Articles Overview** and **Articles Analytics** in the sidebar and added the analytics route.
- Added an analytics dashboard with publishing trends, article status and category mix, topic and SEO-keyword summaries, estimated content reading time, and reader engagement for 7-, 30-, and 90-day periods.
- Added anonymous public article view events and active visible reading-time tracking. These metrics begin with new visits after deployment; no historical reader data is available and no visitor identity is stored.
- Added lazy initialization and schema documentation for the `article_read_views` table.
- Added the article Category column and inline category selection for uncategorized rows; unpublished statuses also have animated inline editing. Only article titles navigate to the editor.
- Updated the user guide, API/routes reference, and root `AGENTS.md` prompt-history and handoff notes.
