# Project Changelog - v1.2.2 (Admin Security Update)

## Milestone: Admin Authentication System

1. **Backend Security**
   - Implemented JWT-based authentication using `jsonwebtoken`.
   - Added environment-based credential verification (`ADMIN_USERNAME`, `ADMIN_PASSWORD`).
   - Created `/api/auth/login` endpoint to handle session creation.
   - Configured `JWT_SECRET` for secure token signing.

2. **Frontend Access Control**
   - Created `LoginPage.jsx`: A modern authentication interface using the project's UI system.
   - Implemented `ProtectedRoute.jsx`: A routing guard that prevents unauthorized access to the admin dashboard.
   - Integrated authentication flow: Login $\rightarrow$ Token Storage $\rightarrow$ Route Access.

3. **Routing Updates**
   - Added `/login` route.
   - Wrapped the `AppShell` and all admin child routes in the `ProtectedRoute` wrapper.
