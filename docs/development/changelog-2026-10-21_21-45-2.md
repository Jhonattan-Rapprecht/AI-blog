# Project Changelog - v1.2.4 (Login Page Theme Toggle)

## Milestone: Dark Mode Toggle on the Login Page

1. **Theme toggle**
   - `LoginPage.jsx` now shows the same sun/moon button as the admin header, in the top-right corner.
   - It uses the shared `useTheme` hook, so the choice is stored in `localStorage` and stays in sync with the rest of the admin app.
   - Previously the login page sat outside `AppShell` and never applied the saved theme.

2. **Theme-aware styling**
   - The page background changed from the hardcoded `bg-slate-50` to `bg-background`.
   - The error message box changed from fixed red shades to the `destructive` theme tokens, so it reads correctly in both modes.
