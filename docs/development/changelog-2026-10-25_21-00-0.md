# Project Changelog - 2026-10-25 (Settings Page and Ollama Model Selection)

## Milestone: Functional Studio Settings

- Added the protected `/settings` page inside the shared admin `AppShell`, retaining the sidebar, header, theme, and component styling.
- Added authenticated `GET /api/settings` and `PUT /api/settings` endpoints. Settings persist in a local `data/settings.json`, which is git-ignored.
- Populated the model selector from the Ollama instance's installed models and validated model changes against that list.
- Routed the saved model into article generation, topic suggestions, and slug suggestions; the sidebar AI status now reflects Ollama connectivity accurately.
- Added persistent defaults for language, tone, audience, and article length. The Editor loads these defaults, allows per-article overrides, and sends length guidance to the generation prompt.
- Renamed the sidebar's `Navigation` group to `Content`.
- After AI generation saves an article, the admin returns to the Articles list, scrolls to the new review item, and highlights it briefly.
- Added an Articles overview button to both new and existing article editor views.

## Documentation

- Updated `docs/development/pages-and-routes.md` with the Settings route, endpoints, persistence behavior, and model-selection details.
