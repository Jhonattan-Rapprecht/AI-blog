# Changelog — 2026-10-26

## Featured images and Media Library

- Added reusable local media storage, image metadata, article image associations, and lazy migration for existing databases.
- Added authenticated media list, validated upload, and safe delete endpoints; files assigned to articles cannot be deleted.
- Added a Media Library page and an Editor featured-image card with preview, upload, and library selection.
- Added editable photo credit/source metadata per media item and small source captions beneath featured images on full article pages; captions are omitted from blog cards and the homepage feature.
- Deferred AI image generation while an image-generation solution is evaluated; provider metadata remains available for a later integration.
- Kept public image crop/fit behavior unchanged; slow zoom-out fitting is deferred for a later change.
- Updated public article cards, homepage, blog filters, and article detail pages to resolve media paths from the API host. Existing `featured_image` URLs remain supported.
- Documented local storage, API routes, and the deferred image-generation capability.

## Analytics title readability

- The Most-read articles table gives the title column 70% of the table width and keeps titles on one line; longer titles use an ellipsis, with the full title available on hover.

## Admin sidebar connection status

- Added a **Connection status** label above the existing Ollama provider/model status at the bottom of the sidebar, with more vertical spacing between the label and details. In collapsed mode, the status dot remains visible and its tooltip includes the connection and model details.
