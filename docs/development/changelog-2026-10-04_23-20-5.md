# Project Changelog - v1.2.1 (Redesign Branch)

## Milestone: Pages Documentation & Article Wrapping Fix

1. **Documentation**
   - Added `docs/user/pages-guide.md`: user guide to every admin and public page with URLs and screenshots, plus how to publish an article.
   - Added `docs/development/pages-and-routes.md`: developer reference of all apps, ports, routes, source files and API endpoints.
   - Added screenshots of all pages in `docs/user/screenshots/`.

2. **Bug Fix: Article Text Wrapping**
   - Quill 2 (`react-quill-new`) serializes every space as `&nbsp;`, so published articles could only wrap at hyphens and overflowed the reading column.
   - The public site now normalizes `&nbsp;` to regular spaces when rendering articles (fixes existing articles).
   - The admin editor now normalizes `&nbsp;` when saving (fixes new and updated articles).
   - Reading time is now calculated correctly (previously the whole article counted as a few "words").
