# Project Changelog - 2026-10-25 (Category-Guided Topic Suggestions)

## Milestone: Use the Editor's Selected Category for Topic Ideas

- The Editor now sends its selected category with topic-suggestion requests.
- Topic suggestions ask for ideas relevant to that category; with no category selected, the model is free to choose topics.
- Removed forced subject-area selection, AI-topic exclusions, and topic-history duplicate filtering. Suggestions are still recorded in topic history.

## Documentation

- Updated the admin user guide and API reference with the category-guided suggestion flow.
