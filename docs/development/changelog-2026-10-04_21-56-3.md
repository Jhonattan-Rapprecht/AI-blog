# Project Changelog - v1.1.0 (Redesign Branch)

## Milestone: Admin Dashboard Redesign
- Rebuilt the frontend on the `redesign` branch using a shadcn/ui-based admin dashboard template (Tailwind CSS v4, plain JavaScript).
- Replaced the monolithic `ArticleEditor.jsx` with a modular structure while keeping all existing editor and AI features.

1. **Template & Styling**
   - Added Tailwind CSS v4 (`@tailwindcss/vite`), shadcn/ui components (button, input, card, badge, sidebar, sheet, tooltip, skeleton, etc.) and `tw-animate-css`.
   - Introduced a neutral, CSS variable-based design system for Light/Dark themes; the selected theme is now persisted in `localStorage`.
   - Themed the Quill editor to match the dashboard via global CSS instead of inline styles.
   - Configured the `@/` import alias (`vite.config.js`, `jsconfig.json`, `components.json`).

2. **Application Shell & Routing**
   - Added `react-router-dom` with routes for New Article (`/`), Articles (`/articles`) and Edit Article (`/articles/:id`).
   - New collapsible sidebar layout (`AppShell`) with navigation, live AI connection status and a header theme toggle.
   - Replaced the custom toast with `sonner` notifications.

3. **Frontend Architecture**
   - Centralized API calls and the Socket.IO client in `src/api/client.js`.
   - Added hooks `useTheme` and `useAIStatus`.
   - Split the UI into `pages/EditorPage.jsx` and `pages/ArticlesPage.jsx`.
   - Removed the obsolete `frontend/frontend/` folder and the unused `App.css`.

4. **New Features**
   - **Articles List**: Table overview of all articles with status badges, creation date, open-to-edit and delete actions.
   - **Edit Existing Articles**: Articles can now be reopened and updated instead of only created.
   - **Publishing Panel**: Status selector (Draft, Review, Scheduled, Published, Archived) alongside category management.
   - **Extended SEO Fields**: Excerpt and SEO description are now editable in the editor.

5. **Bug Fixes & Security**
   - Fixed saving an existing or AI-generated article (now uses `PUT` instead of always `POST`, avoiding duplicate slug errors).
   - Fixed foreign key errors when saving an article without a category (empty value is now sent as `NULL`).
   - Fixed the "Generate" button getting stuck when the Socket.IO event was not received.
   - Hardened `ArticleModel.update` with a column whitelist to prevent SQL injection through request body keys.
