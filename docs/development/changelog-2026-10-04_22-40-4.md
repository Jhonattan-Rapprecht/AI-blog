# Project Changelog - v1.2.0 (Redesign Branch)

## Milestone: Public Blog Site (Astro)
- Added a separate, server-rendered public website in `site/` built with Astro, using the same monochrome black-and-white palette as the admin dashboard.
- The admin editor (`frontend/`) is unchanged in style, layout and color scheme.

1. **Architecture**
   - Three apps in one repository: Express API (`:3000`), React admin (`:5173`) and Astro public site (`:4321`).
   - Astro runs in server mode (`@astrojs/node`), so newly published articles appear immediately without a rebuild and are fully rendered for search engines and link previews.
   - `npm run dev` in the project root now starts all three apps (`dev:server`, `dev:client`, `dev:site`).

2. **Public API**
   - New read-only endpoints under `/api/public` (the existing `/blog` mount keeps working):
     - `GET /api/public/articles`: published articles with `page`, `limit`, `category` (slug) and `q` (search) parameters; returns `{ articles, total, page, limit, pages }`.
     - `GET /api/public/articles/:slug`: a published article including category info, SEO fields and related articles.
     - `GET /api/public/categories`: categories with published article counts.
   - Only articles with status `published` and a `published_at` in the past are visible.
   - Setting an article's status to **Published** in the editor now stamps `published_at` automatically.
   - CORS and Socket.IO accept both the admin and the public site origins (configurable via `CORS_ORIGINS`).

3. **Public Pages**
   - **Landing** (`/`): hero section, featured article, latest articles and topic links.
   - **Blog** (`/blog`): article grid with search, category filters and pagination.
   - **Article** (`/blog/:slug`): reading layout with category, date, reading time, typography styling and "Keep reading" related articles.
   - **Category** (`/category/:slug`): category article list with pagination.
   - **404** page for unknown articles, categories and routes.

4. **Design & SEO**
   - Tailwind CSS v4 with `@tailwindcss/typography`, sharing the admin's color variables.
   - Light/Dark theme toggle without a theme flash on load.
   - Per-page title, description, canonical URL and Open Graph/Twitter meta tags (uses the article's SEO title and description when set).
