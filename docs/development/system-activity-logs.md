# System Activity Logs

## Current state

The `feat/system-activity-logs` branch adds a Developer navigation entry at `/dev/activity-logs` and a placeholder page. It does not yet capture or store system events.

## Intended direction

Provide administrators with an audit trail of important Blogstudio activity across administrator actions and automated jobs. Before implementation, define which events to record, the data fields and actor identity, storage and retention, filters/search, and access controls. Avoid recording secrets or unnecessary sensitive content.
