# Changelog — 2026-10-26

## Blogstudio public categories and editor topic suggestions

- Added an **Uncategorized** filter to the public blog when published articles have no category, including a dedicated category page.
- Topic suggestions now use text entered in the Topic field together with the selected category and retry to collect three distinct suggestions.
- Constrained suggestion chips so long topic titles don’t widen the Editor layout.
- Renamed the admin and public browser titles to **Blogstudio | Admin** and **Blogstudio | AI**.
