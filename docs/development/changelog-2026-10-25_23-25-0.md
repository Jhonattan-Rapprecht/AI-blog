# Project Changelog - 2026-10-25 (Selected Ollama Model Check)

## Milestone: Diagnose Model Selection Problems

- Clarified that changing the model in Settings is a draft until **Save changes** is pressed; the page now shows the model currently active in the app.
- Added an authenticated model check that sends a short JSON-mode request to the selected installed Ollama model and unloads it after the check.
- The check reports the model name, response time, and clear errors for missing, unavailable, empty, invalid-JSON, or timed-out responses.
- Qwen3-family requests disable default thinking mode for JSON tasks, both in the model check and normal AI generation. Empty final responses now report when the model returned reasoning only.

## Documentation

- Added `docs/development/model-picker.md` with the model selection, check, and apply flow.
